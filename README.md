# Auto Ticket Classification using Flow Designer

## Project Description
This project automates the classification of IT support tickets using ServiceNow Flow Designer.

## Features
- Automatically classifies IT tickets based on the Short Description.
- Automatically sets Category and Subcategory.
- Sends confirmation emails to the caller.
- Uses Flow Designer for no-code automation.

## Technology Used
- ServiceNow
- Flow Designer
- Update Sets
